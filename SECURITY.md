# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅                 |
| 5.0.x   | ❌                 |
| 4.0.x   | ✅                 |
| < 4.0   | ❌                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Finly, please report it responsibly.

**How to report:**
- Email: beatrizmazzucatto@gmail.com
- Please do **not** open a public GitHub issue for security vulnerabilities.

**What to expect:**
- You'll receive an acknowledgment within **72 hours**.
- We'll provide updates every **10 days** while the issue is being investigated.
- If the vulnerability is **accepted**, we'll work on a patch and credit you (if desired).
- If the vulnerability is **declined**, we'll explain why it doesn't meet our security threshold.

Thank you for helping keep Finly secure! 🔒
